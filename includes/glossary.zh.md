# 术语表（中文）

全站悬停提示所用的释义 —— 机制见 `hooks/glossary.py`。英文对照文件是
`glossary.md`，两边要同步更新。

两条规则：

- 一行一个词条，`*[术语]: 释义`。释义控制在一句话以内 —— 它要塞进一个提示框。
- 已经有（或将来会有）独立页面的概念，在正文里用**内部链接**，不要在这里建词条。
  所以 AlphaFold、AlphaGenome 这类不收录。

*[神经网络]: 一串简单的数值变换叠在一起，其中的参数不是人写死的，而是从数据里学出来的
*[深度学习]: 用很多层的神经网络做机器学习 —— 关键在于有用的特征是学出来的，不是人手工设计的
*[张量]: 神经网络里装数据和参数的多维数组，可以理解成"轴数不限的矩阵"
*[梯度下降]: 训练过程本身：把每个参数朝着让误差变小的方向挪一点点，反复很多次
*[反向传播]: 把链式法则沿网络倒着算一遍，从而知道每个参数对误差贡献了多少
*[自动微分]: 框架替你求导的能力 —— 你只需要写正向计算，反向的导数它自己算
*[过拟合]: 模型把训练数据背下来了，一碰到没见过的数据反而更差
*[多层感知机]: 最朴素的神经网络：几层全连接层叠起来，层之间夹一个非线性激活函数
*[MLP]: 多层感知机：最朴素的神经网络，几层全连接层叠起来，中间夹非线性激活函数
*[卷积神经网络]: 用一个小滤波器在输入上滑动的网络，因此同一个局部模式出现在哪里都能被认出来
*[CNN]: 卷积神经网络：用小滤波器在输入上滑动，同一个局部模式出现在哪里都能认出来
*[循环神经网络]: 沿着序列一步一步走的网络，一路上带着一份"读到目前为止"的摘要
*[RNN]: 循环神经网络：沿序列一步步走，一路带着"读到目前为止"的摘要
*[注意力机制]: 让模型对每个位置自己决定该去看输入的哪些部分，而不是一视同仁
*[Transformer]: 2017 年提出的、以注意力机制为核心的网络结构，如今是大语言模型和多数生物序列模型的骨架
*[嵌入]: 用一串学出来的数字代表一个离散的东西（一个词、一个基因、一个细胞），相似的东西被放得更近
*[预训练]: 先在一个巨大的通用数据集上把大模型训练一次，得到一个可以被很多下游任务复用的起点
*[微调]: 拿一个预训练好的模型，在你自己那份小得多的数据上再训练一小段
*[大语言模型]: 在海量文本上预训练出来的超大 Transformer，所以能被提示去做它从没被专门训练过的任务
*[LLM]: 大语言模型：在海量文本上预训练的超大 Transformer，能被提示去做没专门训练过的任务
*[独热]: 把每个碱基变成四个格子、在 A/C/G/T 对应的格子里填 1、其余填 0，于是一段序列成了一个 4×长度的矩阵，网络就能读了
*[one-hot]: 独热编码：把每个碱基变成四个格子、在对应碱基处填 1 其余填 0，一段序列于是成为 4×长度的矩阵
*[信号轨迹]: 每个基因组位置一个数值，来自某一种实验在某一种细胞类型上的测量结果 —— 序列模型要学着重现的就是这条覆盖曲线
*[感受野]: 真正能影响某一个输出位置的那段输入序列，通常远短于喂给模型的整个窗口
*[位置权重矩阵]: 一张记录基序里每个位置偏好哪个碱基的表；把它沿序列滑动扫描，和卷积滤波器做的是同一件事
*[PWM]: 位置权重矩阵：记录基序中各位置碱基偏好的表，沿序列滑动扫描的操作与卷积滤波器完全相同
*[基序]: 转录因子这类蛋白质偏好结合的那段短而反复出现的序列模式
*[计算机模拟突变]: 在输入里改动一个或几个碱基、再读一遍模型输出，用来估计这个突变的影响
*[ISM]: 计算机模拟突变：改动输入里的碱基再读模型输出，用来估计一个突变的效应
*[eQTL]: 在群体层面上，与某个基因表达量在统计上相关联的遗传变异
*[caQTL]: 与某段染色质开放程度（可及性）在统计上相关联的遗传变异
*[MPRA]: 大规模平行报告基因实验 —— 一次性测量成千上万到上百万条设计序列的调控活性
*[CRISPRi]: CRISPR 干扰 —— 沉默某个特定调控元件，从而因果地测出它到底控制了什么
*[pseudobulk]: 把同一类型的许多单细胞汇总成一条整体谱，得到比任何单个稀疏细胞都更干净的信号
*[ATAC-seq]: 一种在全基因组范围读取哪些 DNA 片段开放、可及的实验
*[ChIP-seq]: 一种读取某个特定蛋白质在基因组上落在哪里的实验
*[CAGE]: 一种通过捕获 RNA 的 5' 端来读取转录起点位置的实验
*[coding agent]: 把大模型放进一个带工具的循环里运行的程序，它能读你的文件、执行命令、直接改代码，而不只是回答问题
*[harness]: 包在模型外面的那层工具、上下文管理和执行环境，把模型变成 agent；Claude Code 是 harness，Claude 是里面的模型
*[MCP]: 一个开放标准（现由 Linux 基金会托管），让任意 agent 通过同一套接口连接数据库等外部系统
*[diff]: 一个文件前后两个版本之间逐行的改动，git 给你看的就是它，也正是靠它才能把改动撤销
*[SSH]: 一种通过网络安全登录另一台计算机、并在上面执行命令的方式，常用来连接远程服务器或计算集群
*[HPC 集群]: 一套由许多联网机器组成的共享高性能计算系统，你把繁重的任务发过去跑，而不是压在自己的笔记本上
*[登录节点]: 连上集群后最先落脚的那台共享机器，用来编辑文件、提交作业，而不是用来跑繁重计算
