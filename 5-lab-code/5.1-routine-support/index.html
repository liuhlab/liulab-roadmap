    Routine Lab Support¶

    Shared infrastructure the whole lab relies on — knowledge, environments, and reusable tooling for everyday data work. Each project keeps its own full documentation; this page is just a map so you know what exists and where to look.

    Projects¶

    • liulab-roadmap — This site. Curated roadmaps, tutorials, and learning materials for the lab. · Docs

    • liulab-compute-skills — Shared agent skills for the lab, distributed as a Claude Code plugin marketplace. · Docs

    • liulab-runtime — Centralized package and environment manager for lab data analysis, powered by pixi. · Docs

    • liulab-genome — Tools for handling genomic files: metadata management, file processing, and feature extraction (import name genome). · Docs

    • liulab-data — Data curation, download, and organization utilities — for example, fetching datasets from GEO/SRA (import name labdata). · Docs

    Where to go for details

    For how to install or use any project, follow its Docs link — each repo has its own documentation home page.
