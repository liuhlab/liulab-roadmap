# 常规实验室支持

全实验室共享的基础设施 —— 服务于日常数据工作的知识、环境与可复用工具。每个项目
都有各自完整的文档；本页只是一张地图，帮你了解有哪些项目、该去哪里查看。

## 项目

- **[liulab-roadmap](https://github.com/liuhlab/liulab-roadmap)** ——
  本站。实验室的路线图、教程与学习资料合集。
  · [文档](https://liuhlab.github.io/liulab-roadmap/)

- **[liulab-compute-skills](https://github.com/liuhlab/liulab-compute-skills)** ——
  实验室共享的 agent 技能，以 Claude Code 插件市场（plugin marketplace）形式分发。
  · [文档](https://liuhlab.github.io/liulab-compute-skills/)

- **[liulab-runtime](https://github.com/liuhlab/liulab-runtime)** ——
  实验室数据分析的集中式包与环境管理器，基于 [pixi](https://pixi.sh)。
  · [文档](https://liuhlab.github.io/liulab-runtime/)

- **[liulab-genome](https://github.com/liuhlab/liulab-genome)** ——
  处理基因组文件的工具：元数据管理、文件处理与特征提取（导入名 `genome`）。
  · [文档](https://liuhlab.github.io/liulab-genome/)

- **[liulab-data](https://github.com/liuhlab/liulab-data)** ——
  数据的整理、下载与组织工具 —— 例如从 GEO/SRA 获取数据（导入名 `labdata`）。
  · [文档](https://liuhlab.github.io/liulab-data/)

!!! tip "去哪里看细节"
    任何项目的安装与使用方法，请点开它的**文档**链接 —— 每个仓库都有自己的文档主页。
