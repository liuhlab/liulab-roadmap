# 研究项目

实验室围绕具体科学问题开发的研究型代码库 —— 与特定科研问题绑定的模型与流程。每个
项目都有各自的文档；本页负责把你指引过去。

## 项目

- **[bolero](https://github.com/liuhlab/bolero)** ——
  一个以细胞状态为条件的「序列到功能」模型：直接从 DNA 序列预测特定细胞状态下的
  基因调控（染色质可及性与转录本丰度）。
  · [文档与教程](https://liuhlab.github.io/bolero/)

- **[seqforge](https://github.com/liuhlab/seqforge)** ——
  把杂乱的 FASTQ 文件与元数据整理成一份经过校验、与机器无关的测序文库清单
  （manifest），以及可直接运行的 Snakemake 配置。
  · [文档](https://liuhlab.github.io/seqforge/)

!!! tip "去哪里看细节"
    方法、安装与教程请点开各项目的**文档**链接 —— 每个仓库都有自己的文档主页。
