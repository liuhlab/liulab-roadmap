# Research Projects

Research-driven codebases developed in the lab — models and pipelines tied to
specific scientific questions. Each project has its own documentation; this page
points you to it.

## Projects

- **[bolero](https://github.com/liuhlab/bolero)** —
  A cell-state-conditioned sequence-to-function model: it predicts
  cell-state-specific gene regulation (chromatin accessibility and transcript
  abundance) directly from DNA sequence.
  · [Docs & tutorials](https://liuhlab.github.io/bolero/)

- **[seqforge](https://github.com/liuhlab/seqforge)** —
  Compiles messy FASTQ files and metadata into a validated, machine-independent
  sequencing library manifest and a runnable Snakemake config.
  · [Docs](https://liuhlab.github.io/seqforge/)

!!! tip "Where to go for details"
    For methods, installation, and tutorials, follow each project's **Docs**
    link — every repo has its own documentation home page.
