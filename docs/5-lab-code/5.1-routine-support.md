# Routine Lab Support

Shared infrastructure the whole lab relies on — knowledge, environments, and
reusable tooling for everyday data work. Each project keeps its own full
documentation; this page is just a map so you know what exists and where to look.

## Projects

- **[liulab-roadmap](https://github.com/liuhlab/liulab-roadmap)** —
  This site. Curated roadmaps, tutorials, and learning materials for the lab.
  · [Docs](https://liuhlab.github.io/liulab-roadmap/)

- **[liulab-compute-skills](https://github.com/liuhlab/liulab-compute-skills)** —
  Shared agent skills for the lab, distributed as a Claude Code plugin
  marketplace.
  · [Docs](https://liuhlab.github.io/liulab-compute-skills/)

- **[liulab-runtime](https://github.com/liuhlab/liulab-runtime)** —
  Centralized package and environment manager for lab data analysis, powered by
  [pixi](https://pixi.sh).
  · [Docs](https://liuhlab.github.io/liulab-runtime/)

- **[liulab-genome](https://github.com/liuhlab/liulab-genome)** —
  Tools for handling genomic files: metadata management, file processing, and
  feature extraction (import name `genome`).
  · [Docs](https://liuhlab.github.io/liulab-genome/)

- **[liulab-data](https://github.com/liuhlab/liulab-data)** —
  Data curation, download, and organization utilities — for example, fetching
  datasets from GEO/SRA (import name `labdata`).
  · [Docs](https://liuhlab.github.io/liulab-data/)

!!! tip "Where to go for details"
    For how to install or use any project, follow its **Docs** link — each repo
    has its own documentation home page.
